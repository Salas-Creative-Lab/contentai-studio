# ContentAI Studio

🚀 Plataforma Multi-Cliente de Generación de Contenido con IA

## ✨ Características

- 🎨 **Gestión de Clientes** - Branding personalizable por cliente
- 🎛️ **Presets** - Configuraciones de estilo guardadas
- 🤖 **Motor de IA** - Generación automática de contenido
- 📸 **Procesamiento de Imagen** - Fondos automáticos con IA
- 🧠 **Detección de Producto** - Clasificación inteligente
- ✍️ **Generación de Textos** - Títulos, CTAs, hashtags
- 📱 **PWA** - Instalable en dispositivos móviles

## 🛠️ Tecnologías

- **Next.js 15** - Framework React
- **TypeScript** - Tipado estático
- **Prisma** - ORM de base de datos
- **Tailwind CSS** - Estilos
- **shadcn/ui** - Componentes UI
- **Zustand** - Estado global
- **Framer Motion** - Animaciones
- **z-ai-web-dev-sdk** - Integración con IA

## 📦 Instalación Local

```bash
# Clonar repositorio
git clone https://github.com/TU-USUARIO/contentai-studio.git

# Instalar dependencias
bun install

# Configurar base de datos
bun run db:push

# Iniciar servidor
bun run dev
```

## 📱 PWA

La aplicación es una Progressive Web App (PWA) y puede instalarse en:
- Chrome/Edge (PC)
- Android (Chrome)
- iOS (Safari)
